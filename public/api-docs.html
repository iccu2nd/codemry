API Documentation
Akses data akun kamu sendiri (profil & kode publik) lewat API key pribadi.
API Key Kamu
Jangan sebarkan key ini ke orang lain -- siapapun yang pegang key bisa baca data publik akun kamu lewat API.
Memuat...
Cara Pemanggilan
Kirim key kamu lewat header X-API-Key, atau lewat query ?key= kalau lebih gampang. Base URL: /api/public
EndpointKeterangan
GET /api/public/meProfil dasar akun kamu
GET /api/public/snippetsSemua kode publik yang kamu upload
POST /api/public/snippetsUpload kode baru ke akun kamu

Upload Kode Lewat API
Kirim POST ke endpoint di bawah dengan body JSON. Field wajib: filename & content.
FieldTipeKeterangan
filenamestringWajib. Nama file, mis. script.js
contentstringWajib. Isi kodenya
titlestringJudul kode, default = filename
descriptionstringDeskripsi singkat (maks 500 karakter)
languagestringmis. javascript, python, dst
tagsarray/stringMaks 5 tag
isPublicbooleanTampil di feed publik atau tidak
pinstringOpsional, kunci PIN 4-8 digit
POST/api/public/snippets
Contoh Respons
{
  "shortId": "kL9pT2",
  "title": "script.js",
  "filename": "script.js",
  "language": "javascript",
  "isPublic": true,
  "createdAt": 1755311234000
}
Contoh Respons Error
{ "error": "API key tidak valid" }
