Baru pertama kali pakai API? Semua endpoint di bawah dijelasin lengkap -- endpoint, method, butuh API key atau nggak, parameter, sampai contoh kode siap-pakai.
API Key Kamu
API key dipakai buat ngakses endpoint yang butuh login (data akun kamu sendiri). Belum ada key yang dibuat otomatis -- kamu yang generate sendiri kapan mau pakai.
