Panduan Codery
Cara pakai platform share code Codery, dari nol.
1. Daftar & Masuk
Buat akun lewat halaman Masuk pakai username & password. Gak perlu email - cukup ingat username & password kamu buat login lagi nanti.
2. Upload Kode
Tekan tombol + di bottom nav atau Upload Kode di beranda. Kamu bisa:
  • Tempel kode langsung ke kolom Kode, atau upload file (cuma file kode kayak .js, .py, .html, dst - bukan gambar/zip).
  • Isi judul, nama file, dan pilih bahasa pemrogramannya (otomatis kedeteksi dari file yang diupload).
  • Tambahin deskripsi & tag (maks 5) biar gampang ditemuin di pencarian.
  • Atur kode jadi Publik (tampil di feed) atau privat, dan opsional dikunci pakai PIN 4-8 digit.
3. Feed, Like & Simpan
Feed nampilin kode publik dari semua user, ada tab Trending (berdasarkan like & views) sama Terbaru. Tekan ikon hati buat nyuka kode, ikon bookmark buat nyimpen ke daftar Kode Tersimpan di profil kamu.
4. Follow & Profil
Kunjungi profil user lain lewat avatar/nama mereka, lalu tekan Follow. Di profil kamu sendiri bisa edit bio, ganti foto profil/banner, dan lihat daftar followers/following serta semua kode yang kamu upload.
5. Request Scrape
Kalau butuh script scraping buat situs tertentu tapi belum ada yang bikin, kirim permintaan lewat Request Scrape (URL target + deskripsi). User lain bisa "claim" request itu dan bikinin scriptnya, lalu diupload sebagai kode biasa dengan tag terkait.
6. Laporkan Kode
Nemu kode yang vulgar, spam, plagiat, atau berisi malware? Buka detail kodenya, tekan ikon bendera Laporkan, pilih alasan, lalu kirim. Laporan bakal ditinjau tim moderasi.
