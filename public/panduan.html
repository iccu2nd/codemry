Guide Codery
Cara pakai platform share code Codery, dari nol.
1. Daftar & Masuk
Buat akun melalui halaman Masuk menggunakan username dan password. Email tidak diperlukan — cukup ingat username dan password kamu untuk login kembali nanti.
2. Upload Kode
Tekan tombol + di bottom nav atau Upload Kode di beranda. Kamu bisa:
  • Tempelkan kode langsung ke kolom Kode, atau unggah file (hanya file kode seperti .js, .py, .html, dst — bukan gambar/zip).
  • Isi judul, nama file, dan pilih bahasa pemrogramannya (otomatis kedeteksi dari file yang diupload).
  • Tambahkan deskripsi dan tag (maksimal 5) agar mudah ditemukan di pencarian.
  • Atur kode jadi Publik (tampil di feed) atau privat, dan opsional dikunci pakai PIN 4-8 digit.
3. Feed, Like & Simpan
Feed menampilkan kode publik dari semua pengguna, dengan tab Trending (berdasarkan like dan views) dan Terbaru. Tekan ikon hati untuk menyukai kode, ikon bookmark untuk menyimpannya ke daftar Kode Tersimpan di profil kamu.
4. Follow & Profil
Kunjungi profil user lain lewat avatar/nama mereka, lalu tekan Follow. Di profil kamu sendiri bisa edit bio, ganti foto profil/banner, dan lihat daftar followers/following serta semua kode yang kamu upload.
5. Laporkan Kode
Nemu kode yang vulgar, spam, plagiat, atau berisi malware? Buka detail kodenya, tekan ikon bendera Laporkan, pilih alasan, lalu kirim. Laporan bakal ditinjau tim moderasi.
